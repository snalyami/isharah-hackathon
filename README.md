# Isharah Hackathon

Landing page for **Isharah | إشارة**, an AI-powered Saudi Sign Language accessibility platform.

## GitHub Pages

After enabling GitHub Pages from the `main` branch and `/ (root)`, the site URL will be:

https://snalyami.github.io/isharah-hackathon/

Use this stable URL for the poster QR code.

## Updating the demo video later

The landing page currently shows **Demo video coming soon**. When the final demo video is ready, update `index.html` to embed the video or link to YouTube/Google Drive. The GitHub Pages URL stays unchanged, so the printed QR code will continue to work.
